## Цель
Минимальный Mini App, который открывается в Telegram, читает JSON из репозитория и показывает строку "hello, world!".

## Шаги
1. Подтвердить структуру и место контента: `webapp/public/content/hello.json`.
2. Создать минимальный Vite + React webapp, который читает `/content/hello.json` и отображает сообщение.
3. Добавить инициализацию Telegram WebApp (`Telegram.WebApp.ready()`), чтобы приложение корректно открывалось внутри Telegram.
4. Настроить GitHub Pages для webapp (сборка и публикация статических файлов).
5. Проверить end-to-end: открыть Mini App по GitHub Pages URL в Telegram и увидеть "hello, world!".

# План этапа 5 — практика “Словарь”

## Цель
Реализовать первый рабочий блок упражнений: выбор правильного ответа из 4 вариантов для темы “Базовые фразы”.

## Шаги
1. Добавить экран “Выбор темы”, который открывается по клику на карточку “Словарь” в разделе “Практика”.
2. Добавить на экран “Выбор темы” первую карточку: “Базовые фразы”.
3. Подготовить runtime-модель вопроса для single-choice: `prompt`, перемешанный массив `options`, `correctIndex`.
4. Реализовать загрузку контента первого элемнта из `webapp/public/content/practice/basic_phrases.json` по структуре из `docs/practice-content.md`. Сделать макет экрана вопроса с этими данными. 
5. Реализовать механику "перемешивания" вариантов ответов
6. Реализовать механику выбора ответа:
    - при клике на один из вариантов ответа, необходимо проверить совпадает ли выбранный вариант с правильным ответом
    - после выбора ответа кнопки с ответами становятся не кликабельные, то есть можно выбрать ответ только один раз
    - после выбора ответа фон правильного ответа необходимо расскрасить в зеленый цвет
    - если полььзователь ответил неверно, но фон выбранного неверного ответа необходимо покрасить в красный 
7. Реализовать механику перехода к следующему вопросу
    1. чтобы сделать рэндомный порядок необходимо сделать следующее
        - создать массив incrArray, размер = размер массива контента basicPhrases (для базовых слов это webapp/public/content/practice/basic_phrases.json)
        - заполнить его числами инкрементами, то есть 0, 1, 2, 3, ... 
        - перемешать этот массив инкрементов, полученный массив пусть будет shuffleIncrArray
    2. При открытии упражнения (в данном случае при клике на "Базовые слова") отобразить первый вопрос basicPhrases[shuffleIncrArray[0]]
    3. Следующий вопрос открывается при клике на кнопку "Далее"
    4. Следующим вопросом отобразить basicPhrases[shuffleIncrArray[1]], затем basicPhrases[shuffleIncrArray[2]] и т.д. 
    5. Когда элементы в shuffleIncrArray закончаться, начать сначала, то есть снова отобразить basicPhrases[shuffleIncrArray[0]]
    6. shuffleIncrArray живет только пока открыт режим упражнения. При выходе из режима он удаляется. При повторном входе в режим       упражнения (в данном случае снова кликнуть на "Базовые слова") создается новый массив incrArray, затем shuffleIncrArray по описанному выше алгоритму
