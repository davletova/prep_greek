# Источники заданий по глаголам

## Пересмотренный список A1

`a1-reviewed.txt` — 79 глаголов в шести темах в порядке пользовательского списка.
Каждая строка содержит формы настоящего времени, их русские переводы и контексты
`греческий~русский`. Для каждой личной формы обязателен отдельный контекст:
шесть для обычного глагола, два для `αρέσει / αρέσουν` и `κοστίζει / κοστίζουν`.
Циклическое повторение фраз для разных местоимений запрещено генератором.
Все 466 контекстов различаются даже после удаления начального местоимения
и пропуска. Лексика предложений охватывает A1–A2, сами целевые глаголы остаются
из пользовательского списка A1. Используются разные существительные,
прилагательные, наречия и предложные конструкции (например, `κατά μήκος`,
`ανάμεσα`, `μακριά από`). Тест фиксирует не менее 600 разных словоформ
в контекстах; это не число лемм и не автоматическая оценка уровня CEFR.

`a1-reviewed-glosses.json` дополняет словарные подсказки из архивных заданий
`practice/`. Эти архивы и задания A2 не меняются при генерации.

Из корня репозитория:

```sh
node webapp/scripts/generate-reviewed-a1-verbs.mjs
npm run validate:content --prefix webapp
```

Генератор заменяет только `public/content/practice/single_choice/verbs-a1/`.
Получаются 466 вопросов: 77 глаголов × 6 лиц, плюс два вопроса с `αρέσει / αρέσουν`
и два с `κοστίζει / κοστίζουν`. У последних двух глаголов используются только
естественные для начального уровня конструкции третьего лица. Варианты через
косую черту (`μιλάω / μιλώ` и т. п.) считаются одним глаголом; в ответах выбрана
одна согласованная парадигма.

В каждом вопросе четыре варианта по схеме **два глагола × две одинаковые
грамматические формы**. Например: `πίνουμε / πίνετε / τρώμε / τρώτε`.
`a1-distractor-verbs.json` задаёт для каждого целевого глагола объект
`{ "verb": "…", "context": "…" }`: близкий по смысловой области отвлекающий
глагол и короткое пояснение ситуации. Формы и переводы берутся из того же
списка A1. Пояснение остаётся только редакторской заметкой в исходнике:
в `translation` и перевод в подсказке оно не добавляется, чтобы не подсказывать
ответ. При редактировании греческого контекста нужно обновлять его
русский перевод и добавлять отсутствующие словарные подсказки в
`a1-reviewed-glosses.json`; генерация завершается ошибкой, если слово не переведено.

Пары подбираются редакторски, а не случайно: например, `αρχίζω / τελειώνω`,
`ψάχνω / βρίσκω`, `πεινάω / διψάω`. Редакторская заметка описывает задуманную
ситуацию. Некоторые короткие греческие фразы вне этой ситуации допускают
оба глагола; при выборе ответа учитывается также русский перевод.
Не следует использовать настоящие контекстуальные синонимы: например,
`παίρνω` также может означать «покупать», поэтому для `αγοράζω` выбрано
`αλλάζω` с уточнением «новая покупка, не обмен».

Генератор исключает
совпадающие написания (например, `είναι` в двух лицах). Для `αρέσει / αρέσουν`
и `κοστίζει / κοστίζουν` оба глагола стоят в третьем лице единственного
и множественного числа. Подсказки включают переводы всех трёх неверных ответов.

Новые ID отделены от старых, чтобы прежние ответы не засчитывались как
выполненные новые задания. Старые скрипты `split-verb-levels.mjs` и
`add-verb-word-hints.mjs` относятся к предыдущему набору: после их запуска
нужно заново сгенерировать пересмотренный A1.
