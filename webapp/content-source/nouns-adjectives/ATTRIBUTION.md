# Источники и лицензирование корпуса

## Определение объёма A1+A2

Списки слов для первичного отбора сверялись с греко-английскими глоссариями учебников «ΚΛΙΚ στα ελληνικά» уровней A1 и A2 Центра греческого языка:

- https://www.greek-language.gr/certification/sites/greeklanguage.gr.certification/files/KLIK_A1_Ef_Glossary.pdf
- https://www.greek-language.gr/certification/sites/greeklanguage.gr.certification/files/KLIK_A2_Ef_Glossary.pdf

Определения, примеры и английские переводы из глоссариев не копируются. Глоссарии используются только для определения примерного лексического объёма уровней.

## Грамматические формы

Грамматические формы в `lexicon-candidates.json` получены из машиночитаемых данных Kaikki/Wiktionary:

- Kaikki Greek dictionary: https://kaikki.org/dictionary/Greek/
- Исходный проект Wiktextract: https://github.com/tatuylonen/wiktextract
- Лицензия: Creative Commons Attribution-ShareAlike 4.0 International  
  https://creativecommons.org/licenses/by-sa/4.0/

Производные данные форм в этом каталоге распространяются на условиях CC BY-SA 4.0. Русские переводы словосочетаний и тематическая классификация создаются отдельно в рамках проекта.

Файл `lexicon-candidates.json` является рабочим инвентарём. Статус `imported` означает успешное автоматическое сопоставление, а не завершённую лингвистическую проверку.
